# xangi-studio連携スキル

「この草案をxangi-studioに渡して」「原稿をAIで修正して」「このPRを取り込んで」といった依頼を、ホスト内の拡張APIへつなぎます。別のxangiインスタンスへの送信設定は不要です。特定の利用者や原稿の種類には依存しません。

## 導入と使い方

[XANGI_SETUP.md](../../XANGI_SETUP.md#チャット用スキルの導入)に従って、利用する各workspaceへ製品同梱スキルの参照を追加します。必要なのはNode.jsと、稼働中のxangiが提供するCLI・tool serverです。追加のnpm/Python依存やAPIキーはありません。

例：「この原稿をxangi-studioに保存して。レビューはまだ不要」。スキルは保存結果を再取得し、成果物の画面リンクを返します。AI向けの判断と操作手順は[SKILL.md](SKILL.md)にあります。

PRや原稿を話題にした後の「あとstudioにも送って」でも、同じホストの拡張へ保存します。Mac Studioなど別の機器への転送とは区別し、保存だけの依頼で新たなAIレビューは開始しません。

## 接続先が見つからないとき

拡張の登録・起動と、スキルの発見は別です。拡張が正常でも、workspaceにスキルがなければ呼び出し方が伝わらない場合があります。導入スクリプトの `--check` と新しい会話のスキル一覧を確認してください。同名の既存スキルがある場合は上書きせず、製品版との統合を判断します。

## 閲覧リンクを開けないとき

`web_status` がlocalhostだけを返す場合があります。別端末向けには既存のHTTPS/Tailnet接続先を確認し、確認できなければ現在のxangi画面のExtensionsから成果物を開く経路を案内します。保存の成功と端末からの接続確認は別で、ネットワーク設定は自動変更しません。
